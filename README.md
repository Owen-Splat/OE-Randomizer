# OE-Randomizer
A randomizer for the Octo Expansion DLC for Splatoon 2

This mod is NOT online safe. Please use emummc, emulator, or an already banned console

## Information
This randomizer includes options for randomizing weapons, levels (including the 4 thangs needed to progress to the final stages of the story), ink color, music, and more! An additional option exists for a One-Hit KO "Enemy Ink Is Lava" challenge

With weapons randomized, every level is given 3 choices regardless of how many are in the vanilla level. Additionally, the randomizer includes a setting to leave the first choice left vanilla to ensure every playthrough is able to be completed

It is recommended to play on version 4.6.0 or later. Older versions will not have all the weapons included in the randomizer pool, resulting in being given no weapon
